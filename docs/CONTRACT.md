# Kiekkist – contract (v0.1, 29.10.2026)

Single source of truth for everyone building parts of Kiekkist. Language of code, UI strings and docs: **English** (UI may get a German translation later). Stack: Node 22 ESM, Hono, better-sqlite3, Playwright 1.63, Vanilla CSS with OKLCH tokens. No React, no Tailwind, no build step for the frontend.

## Concepts

| Term | Meaning |
|---|---|
| **Reference** (`ref`) | A captured external page: URL, screenshots, extracted tokens, tags, judgment. Private material. |
| **Board** | A project moodboard: brief, collected refs with notes, 2–3 directions, a decision. |
| **Direction** | One distinct design route on a board: name, thesis, tokens, a real HTML preview page (`index.html`), the refs it draws from. |
| **Decision** | Human choice of a direction (optionally "combine A's type with B's layout"), dated, with reason. |
| **Theme** | A finished, reusable design: DESIGN.md, tokens.css, tokens.json (DTCG), pages (HTML), optional slides/social/app pages, screenshots, check report. Own work only. |
| **Judgment** | The owner's verdict on a ref/theme/direction: `love` · `like` · `meh` · `no`, plus a free note ("why"). Feeds the taste profile. |
| **Profile** | Markdown summary of judgments (what he keeps choosing / rejecting, by mechanism). Read by agents before any design work. |
| **Source** | A curated inspiration gallery or marketplace with what it is good for (industry filters, URL patterns). |

## Storage layout

`DATA_DIR` (default `./data`):

```
data/
  kiekkist.db            # SQLite
  refs/<refId>/             # shot-desktop.jpg, shot-desktop-2.jpg, shot-desktop-3.jpg, shot-mobile.jpg, full.jpg, page.html (optional), tokens.json
  boards/<boardId>/directions/<dirId>/index.html (+ assets)
  themes/<themeSlug>/       # see Theme format
```

## Theme format (folder, also the ZIP export and what examples/themes/* contain)

```
<slug>/
  theme.json      # {structure?: [section types in order, for rotation], slug,name,summary,industry[],media[],mood[],fonts[],license,author,created,source_direction?}
  DESIGN.md       # Google design.md style: YAML front matter with tokens + sections Overview, Colors, Typography, Layout, Components, Imagery, Motion, Do/Don't
  tokens.json     # W3C DTCG
  tokens.css      # :root custom properties, OKLCH colours
  pages/index.html          # required: web home page, self-contained (links ../tokens.css allowed), real copy, no lorem ipsum
  pages/*.html              # optional further pages
  slides/*.html             # optional 1920x1080 slides
  social/*.html             # optional 1080x1080 / 1080x1350 / 1200x630 cards
  app/*.html                # optional 390x844 app screens
  # every slide/social/app file declares its canvas: <meta name="kk:size" content="1200x630">
  assets/                   # images, self-hosted fonts (woff2) – only freely licensed or own
  shots/                    # generated by Kiekkist: <page>-desktop.jpg, <page>-mobile.jpg
  check.json                # generated: latest check report
```

## Database (SQLite)

- `refs(id TEXT PK, url, title, domain, captured_at, status['queued','ok','error'], error, industry JSON, tags JSON, media TEXT default 'web', mechanism TEXT, note TEXT, judgment TEXT, judged_at, tokens JSON, source TEXT, origin TEXT)`
- `boards(id PK, name, client, brief TEXT, status['collecting','directions','decided','done'], created_at, updated_at, share_token)`
- `board_refs(board_id, ref_id, note, PRIMARY KEY(board_id, ref_id))`
- `directions(id PK, board_id, name, label['safe','middle','bold',null], thesis, tokens JSON, ref_ids JSON, preview_path, created_at, judgment, note)`
- `decisions(id PK, board_id, direction_id, combine_note, reason, decided_by, decided_at)`
- `themes(slug PK, name, summary, industry JSON, media JSON, mood JSON, created_at, updated_at, judgment, note, check_score REAL, check_at, origin['example','own','client'])`
- `sources(id PK, name, url, kind['gallery','marketplace','directory','agency'], good_for TEXT, industries JSON, search_url_template TEXT, note)`
- `events(id PK AUTOINCREMENT, at, kind, subject, payload JSON)` – audit + profile input

Stored files: capability URLs `/v/<refs|boards|themes>/<id>/<mac>/<path>` (HMAC over kind/id, for boards also the share token). They open without login (share links, sandboxed previews, agents). HTML and SVG are served with `Content-Security-Policy: sandbox allow-scripts allow-popups`, so stored pages run in an opaque origin and cannot use the owner's session. The data directory itself is never served.

Security model (29.10.2026): fail closed (KK_PASSWORD >= 12, KK_TOKEN >= 24 characters, otherwise only `HOST=127.0.0.1 KK_INSECURE_LOCAL=1`); random server-side sessions (14 days, POST /logout); login throttling per IP; Origin/Sec-Fetch-Site check on cookie writes; strict CSP and security headers; `?key=` on /mcp only with a separate `KK_MCP_KEY`; Chromium runs as an unprivileged user behind a local egress proxy (`src/egress.js`) that allows only ports 80/443 to public IPs (redirects, frames, workers and WebSockets included, no DNS rebinding); at most `KK_MAX_CONTEXTS` (2) browser contexts at once, idle browser closed after 5 minutes.

## MCP tools (server at `/mcp`, Streamable HTTP, bearer token; and `node cli/kk.js mcp` for stdio)

`kk_search_refs`, `kk_add_ref`, `kk_get_ref`, `kk_judge`, `kk_list_sources`, `kk_gallery_search`, `kk_create_board`, `kk_get_board`, `kk_add_to_board`, `kk_add_direction`, `kk_decide`, `kk_list_themes`, `kk_get_theme`, `kk_save_theme`, `kk_check`, `kk_profile`; export and launch: `kk_export`, `kk_export_tokens`, `kk_launch_check`, `kk_launch_sheet`, `kk_processors`, `kk_dns_plan`, `kk_legal_inputs` (see below).
`kk_judge` takes {kind:'ref'|'theme'|'direction', id, judgment, note}.
`kk_check` takes {theme?|url?|html?, profile?, pages?, perf?, mobile?, brand_fonts?, banned?, detail?}. `kk_gallery_search` takes {q?, industry?, medium?, free?, limit?}; it only searches and links, designs come through the gallery's remote MCP `/mcp-gallery` (get_free_design; get_design with a licence key) or its website.

UI (30.10.2026): board references as a dense CSS grid (grid-auto-flow: dense, capture aspect ratios, loved refs double size), tag filter and phone view via query (`?tag=`, `?view=mobile`), move buttons and a position field (POST /ui/boards/:id/refs/:ref/move), bookmarklet "Save to Kiekkist" → GET /ui/refs/new?url=&board= (small window; in token mode one same-site bounce for the SameSite=Strict cookie, then /login?next=).

## Check module interface (`src/check/index.js`)

```js
export async function checkTarget({ url, html, file, tokens, viewports = [390, 768, 1440], browser, profile, pages, mobile = true, perf = false, brandFonts, banned }) => Report
// banned: counted signal ids (tells pack) that are hard errors (rule house-banned) at their first occurrence; unknown ids throw
// Report = { score: 0-100, grade: 'A'..'E', at, target, viewports, hard: Finding[], counts: Counter[], findings: Finding[], summary: string }
// Finding = { rule, severity: 'error'|'warn'|'info', viewport?, selector?, detail, value? }
// Counter = { rule, label, count, threshold, over: boolean }  // slop signals are COUNTED with thresholds, not banned
```
Measurement state (30.10.2026, rules 2026-10-30.4): before contrast and axe the page is settled (`settle()` in `probe.js`): wait until no short time-based CSS/Web Animation runs and the DOM has been quiet for 350 ms (cap 3 s; before axe 150 ms, cap 1.5 s); short animations still running at the cap are finished; long ones (infinite or ending after 5 s) are cancelled for the measurement and restarted (`resumeMotion()`) before the motion checks; scroll-driven animations are left alone. If anything moved during the measurement it is settled and measured once more. Report: `stats.settle[vw] = {ms, finished, frozen, capped, remeasured}`.

Also `src/check/cli.js <file|url> [--tokens tokens.json] [--json] [--page …] [--profile …] [--perf] [--no-mobile] [--brand-font …] [--ban …]`.

## Taste profile (`GET /profile?format=md`)

Markdown: last updated, counts, then sections "Keeps choosing", "Rejects", "Mechanisms that work", "Notes in his words" (verbatim notes), "Recently decided directions". Built from judgments + decisions + notes; never invent.

## Export (`src/export/`, 30.10.2026)

Local only: `kk export` reads a theme folder and writes a scaffold; no server, no upload. Pipeline: `load.js` (theme folder) → `validate.js` → `ir.js` (intermediate representation) → `targets/<target>.js` → write → post-export check (`index.js`).

```js
import { exportTheme, exportTokens, listTargets } from './src/export/index.js';
await exportTheme({ themeDir, target, out, siteUrl?, lang?, name?, cms?, force?, build?, check = true })
// -> { ok, code: 0 | 1 (post-export check failed) | 2 (theme refused), out_dir, files, notes[], validation: {errors, warnings, info}, check }
exportTokens(themeDir, 'css' | 'theme.json' | 'tailwind' | 'elementor') // -> string
```

**Section naming:** each top-level `<section>` is named by `data-section`, else `id`, else the id its `aria-labelledby` points to (suffix `-title`/`-t`/`-heading` dropped; ids under three characters fall back to the heading text, reported as info). A section without any name refuses the export (exit 2). `<header>` and `<footer>` directly under `<body>` (or under a wrapper div) are sections `site-header` / `site-footer`. Same name with different markup on another page becomes `<page>-<name>`.

**IR:** `{ site, tokens: {css, dtcg}, pages: [{slug, path, title, description, og, lang, parts, sections}], sections: {name: {component, kind, props: [{key, kind: text|rich|image|link|attr, attr?, value}], collections, pages, node}}, collections: {name: {fields, items: [{id, order, …}]}}, assets: [{path, kind, alt, credit, license, ai}] }`. Props carry the original wording (no rewriting); repeated siblings with the same tag tree (≥ 3, or 2 with the same class) become a collection; attributes that differ between items become fields. Image manifest (optional): `assets/img/manifest.json` or `theme.json` `"images": {"file.jpg": {alt, credit, license, ai}}`.

**Token files** (`src/export/tokens/`): `toCss` (naming as in the themes' tokens.css: `--c-*`, `--font-*`, `--fs/fw/lh/ls-<role>`, `--space-*`, `--radius-*`), `toThemeJson` (WordPress v3, palette/sizes/fonts locked, bridge CSS mapping `--c-*` onto `--wp--preset--*`), `toTailwindTheme` (v4 `@theme`, defaults reset), `toElementorSettings` (hex fallback, clamp → desktop/tablet/mobile, `lossy: true`), `shadcnCss`/`shadcnRoles` (shadcn/ui variables as aliases of the tokens).

**Targets** (`src/export/targets/index.js`, `kk export --list`):

| Target | Status | Output |
|---|---|---|
| `html` | ready | pages at the root, legal stubs, 404, sitemap, robots, `.htaccess` + `_headers` with security headers |
| `astro` | ready (Astro 7, builds) | section components with typed props, `content.config.ts` (sections + one collection per list), Base layout, CSP on, `--cms` configs |
| `react` | ready | Tailwind v4 `@theme` + shadcn variables, TSX section components, page compositions, `registry.json` + `r/*.json` (shadcn registry), `npm run preview` renders with react-dom/server. The path for Next.js, TanStack Start (Lovable), Vite (Bolt), v0 |

Adapter contract: `export const meta = {id, tier, status, label, versions, editable}`; `export async function exportTarget(ir, opts) -> { files: Map<path, string|Buffer>, notes: string[], postCheck: { buildCmd?, buildDir?, serveDir?, preview?: {files, pages}, pages, sourcePages } }`.

**Post-export check:** pages are served from 127.0.0.1 (`serve.js`); `checkTarget` runs on each exported page and on the theme pages as baseline; hard errors the theme does not have are regressions (the theme baseline runs with mobile: false to save the lab run, so mobile-group findings of the export are listed per page in EXPORT.md but never counted as regressions); any request off the export's origin fails; `compareTargets(theme index, export index)` must say **too similar** (faithful export). Without `--build` the check uses a static preview rendered from the exported templates and data; with `--build` it runs `npm install && npm run build` (Astro) or `npm run preview` (React) and checks the real output. WordPress and Elementor have no automatic visual check yet. `EXPORT.md` in the output records target, versions, editability, notes, check.

## Launch (`src/launch/`, 30.10.2026)

`kk launch <url|export-dir>` runs the automatic checks of `skill/web-design-studio/references/launch.md` and writes `launch-report.json` + `.md` next to the launch sheet (`.kiekkist/launch/<host>.md`). Exit 0 = no automatic errors, 1 = errors, 2 = unreachable or not public.

```js
import { runLaunch } from './src/launch/index.js';
await runLaunch({ target, only?: ['dns','tls','privacy','legal','search','perf','forms','a11y','ops','handover'], pages = 20, sheet?, formEndpoint?, formTest?, processors?, recheck?, a11yPages = 3, perf = true, outDir? })
// -> { rules_version, summary, counts, findings: [{id, key?, severity: error|warn|info|pass, ok, detail, evidence}], foreignHosts, manual_open, processors?, changes?, disclaimer, code }
```

Modules: `dns.js` (A/AAAA/CNAME, MX, SPF with recursive lookup count, DKIM per sheet selector, DMARC, CAA), `http.js` (`safeFetch` with SSRF re-check per redirect, TLS certificate, http→https, apex↔www, security headers, robots, sitemap, 404, favicon, llms.txt), `crawl.js` (Playwright, observe only: request log, cookies and storage before interaction, iframes, DOM facts, lab LCP/CLS/bytes at 390 px throttled; the a11y page checks therefore call checkTarget with mobile: false), `checks.js` (privacy, legal, compliance-claim wording, SEO, forms, AI notices), `sheet.js` (launch sheet, append-only, secret-looking values refused), `plan.js` (processors table, DNS plan, the twelve privacy-policy inputs). Form test: only with `--form-test`, exactly one marked POST to the site or the sheet's endpoint. Live targets must be public; a local folder is served on 127.0.0.1 and skips DNS/TLS/headers.

MCP tools (all state "prepares and verifies; never registers, pays, signs or changes DNS"): `kk_export`, `kk_export_tokens`, `kk_launch_check`, `kk_launch_sheet` (tick only with `relayed_from_owner=true`), `kk_processors`, `kk_dns_plan`, `kk_legal_inputs`. On the HTTP MCP server `theme_dir`/`out` are refused (themes by slug, output under `DATA_DIR/exports`, sheets under `DATA_DIR/.kiekkist/launch`); `kk mcp` (stdio) allows local folders.
